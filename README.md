# TOEIC Part 5 Practice Tool

Tool luyện thi TOEIC Part 5 (Reading - Incomplete Sentences).

## Tính năng

- Luyện tập 109 câu hỏi TOEIC Part 5
- Hiệu ứng âm thanh khi trả lời đúng/sai
- Giao diện thân thiện, responsive

## Sử dụng

Mở file `toeic_part5.html` trực tiếp trên trình duyệt hoặc deploy lên GitHub Pages.

## Cấu trúc

```
toeic/
├── toeic_part5.html   # Trang chính
├── app.js             # Logic ứng dụng
├── data.js            # Dữ liệu câu hỏi
├── styles.css         # Giao diện
├── audio.mp3          # Audio bài nghe
├── correct.mp3        # Âm thanh trả lời đúng
├── wrong.mp3          # Âm thanh trả lời sai
├── incomplete.mp3     # Âm thanh chưa hoàn thành
└── favicon.jpg        # Icon trang web
```
